# Contributing

Thank you for helping improve XPay for WooCommerce.

## Bug reports

Before opening an issue:

1. Update to the latest plugin, WordPress, and WooCommerce versions.
2. Check the [troubleshooting guide](docs/TROUBLESHOOTING.md).
3. Reproduce the problem with other checkout customizations disabled when possible.
4. Turn on XPay diagnostic logging and note the relevant WooCommerce order number.

Include the plugin, WordPress, WooCommerce, and PHP versions; the checkout type; clear reproduction steps; and the expected and actual result.

Never post API keys, webhook secrets, card details, personal data, or unredacted logs. The plugin's XPay log is redacted before it is written, but review it before attaching it.

## Feature requests

Open an issue describing the merchant problem, the expected behavior, and why existing settings do not solve it.

## Pull requests

This public repository is the release mirror for XPay for WooCommerce. Development happens in XPay's private development repository, so unsolicited pull requests cannot be merged directly. Open an issue first. Accepted fixes may be applied to the development repository and credited in the release notes.

## Security issues

Follow [SECURITY.md](SECURITY.md). Do not disclose vulnerabilities in issues or pull requests.
