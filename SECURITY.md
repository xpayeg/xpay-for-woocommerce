# Security policy

## Supported versions

Security fixes are provided for the latest released version of XPay for WooCommerce.

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue.

Use the public repository's **Security → Report a vulnerability** form. This creates a private security advisory visible only to the reporter and XPay's maintainers.

If private vulnerability reporting is temporarily unavailable, contact XPay support through [xpay.app](https://xpay.app/) and ask for the security team. Do not include API keys, webhook secrets, card details, personal data, or an exploit in the first message.

Include:

- The affected plugin version.
- The affected WordPress and WooCommerce versions.
- A clear reproduction using test mode.
- The security impact.
- Any suggested remediation.

XPay will acknowledge the report, investigate it privately, and coordinate disclosure after a fix is available. Payment data must only be tested with accounts and stores you are authorized to use.
